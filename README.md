# Conway's Game of Life - NetLogo Edition

## How to Run
1. Download [NetLogo](https://ccl.northwestern.edu/netlogo/)
2. Open `game-of-life.nlogo`
3. Click "Setup" then "Go"

## Features
- **spawn-glider**: Creates a small diagonal traveler
- **spawn-glider-gun**: Builds a gun that shoots gliders forever
- **spawn-pulsar**: Beautiful oscillating pattern
- **spawn-lwss**: Lightweight spaceship
- **random-fill**: Randomly populates 20% of cells
